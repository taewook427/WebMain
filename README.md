# WebMain

Main website with portal links, language stats and D-Day trackers

- DevHistory: 나와 동료들의 프로젝트 개발사 Development project history of me and my colleagues
- GithubStats: 깃허브 언어통계를 보여주는 HTML 패치 생성기 HTML generator for GitHub language statistics
- gr1_test610: 연세대 1학년 강의 담은수 분석 Analysis of Yonsei Univ freshman lecture data
- kzip-lite: 인브라우저 ZIP/TAR/7Z 압축과 해제 도구 In-browser ZIP/TAR/7Z compressing tool
- py_copycheck: 간단한 파이썬 코드 일치도 검사기 Simple Python code checker
- WebClock: 초단위 시계, 타이머, 스톱워치 Second clock, Timer, Stopwatch
- WebHex: 인브라우저 바이너리 헥스 뷰어 In-browser binary hex viewer
- YAS-web-lite: k-atusa/YAS의 경량화 웹 버전 Lightweight web version of k-atusa/YAS
